# Com: a Student Life Dashboard Tracker

A student productivity web application built with React and Supabase.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Supabase
- PostgreSQL

## Features (Planned)

- Authentication
- Subject Management
- Assignment Tracker
- Notes
- Calendar
- AI Summaries
- AI Quiz Generator
- AI Flashcards

## Getting Started

```bash
npm install
npm run dev
```

Create a `.env` file based on `.env.example`.
